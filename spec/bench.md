# R5 실물 시험

## B25 실물 시험

시험한 B25 CAD의 SHA-256, 출력 조건, 실제 부품, 카메라 선과 A4 허브, 펌웨어와 실측 `Calibration.h`를 식별합니다. 결과는 시험한 사람이 [검수 기록 형식](records/README.md)에 따라 남깁니다. [고정 검사 조건](conditions.md) · [B25 조립](../mechanical/revisions/b25/assembly.md)

1. 하드웨어 없이 모형 검사와 영상 미리보기를 실행합니다. 시험 출력물에서 P01과 P08의 건식 맞춤을 시작합니다. [제어와 보정](../control/README.md)
2. 모터를 뺀 상태에서 A4 입력과 출력, OpenRB USB 응답을 확인합니다. 최종 경로에 놓은 카메라 선의 도통·단락 검사와 High-Speed 영상을 확인합니다. [A4 첫 통전](../electronics/README.md#전원-실물-검수) · [카메라 선 조립](../mechanical/revisions/b25/assembly.md#카메라-usb-선재)
3. P08 턱 받침–요크의 건식 간극을 확인합니다. 목과 턱을 받치고 토크 OFF를 확인한 뒤 P04 목과 P06 턱의 스토퍼 여유를 재고 보정합니다. 간극이나 스토퍼 여유가 기준에 미달하면 해당 축에 토크를 켜기 전에 기록하고 조립 상태를 확인합니다. 한 축씩 방향과 간극을 확인한 뒤 조립품에서 아래 P01–P08 항목을 마칩니다. [보정과 한 축 구동](../control/README.md#보정과-한-축-구동)

### P03 눈꺼풀 단독 구동

보정과 한 축 확인을 마치고 목과 턱을 받칩니다. 얼굴이 계속 검출되도록 카메라 앞에 둔 채 실행합니다. 영상에서 눈꺼풀이 닫히고 다시 열린 완전한 50회 이상을 연속으로 확인합니다. 얼굴 소실이나 구동 중단이 있으면 연속 구간을 다시 셉니다. 연속 구동에서 걸림이 0회이고, 각 깜빡임이 **0.8~1.5초**, 시작 간격이 **4~10초**일 때 합격으로 기록합니다. 종료 후 목과 턱을 받친 채 토크 해제를 확인합니다. [해제 절차](../control/README.md#보정과-한-축-구동)

```sh
python control/pc/track.py --source 0 --serial /dev/ttyACM0 --drive --axes blink --immediate-hold
```

### P04·P05 전시 추적

전시 추적에서 목을 정면에 두고 앞 1.5 m 선을 0.8 m/s로 양방향에서 지나갑니다. 대상 방향과 눈·목 움직임을 같은 시각 기준으로 기록합니다. 첫 가시 프레임부터 시선 오차 10° 이내까지 **1초 이하**, 포착부터 반대쪽 80°까지 **85% 이상**의 시간 동안 시선 오차 10° 이하, 추적 중 목 합성 각속도 **45°/s 이하**를 확인합니다. 미검출 구간도 평가 시간에 포함합니다. 정지한 추적 자세에서 얼굴을 가려 마지막 시선을 **2~3초** 유지한 뒤 **15°/s 이하**로 정면에 복귀하는지 확인합니다. 유지 중과 복귀 중에 새 얼굴을 보여 주고 눈이 목보다 먼저 새 방향으로 움직이는지 촬영합니다. [전시 추적 명령](../control/README.md#전시-추적과-턱-시험) · [S01 판정](requirements.md#동작-장면)

S01b는 정면에서 양쪽 40° 대상을 향할 때 목의 넘침 **12° 이하**와 정지 후 수평 시선 오차 **10° 이하**를 확인합니다. S01·S01b는 수치와 시험자 판정을 P04·P05 계측 근거에 함께 남깁니다. 검사기의 S01·S01b 행은 추적 모형 결과를 표시합니다. [인수 검사 범위](requirements.md#b25-인수-검사)

### P06 턱 구동과 복구

표의 스토퍼 여유를 확보한 뒤 실측한 보정표에서 ID6의 `abs(high - zero)`가 **62틱**인지 확인합니다. 목을 중립에 받치고 턱 시험 모드를 실행합니다. 두 번째 열림에서 닫힘 자세 대비 턱 끝의 수직 하강량을 잽니다. `jaw_stop_reserve_deg`는 `(열림 쪽 마지막 무접촉 틱 - 62 - 5) × 360 / 4096`입니다. 턱 시험 모드에서 펌웨어는 ID6 Goal PWM을 **160**으로 쓰고 다시 읽어 확인한 뒤 토크를 켭니다. 시험에 사용한 펌웨어와 정상 구동을 근거로 남깁니다. B25 CAD의 하강량은 **5.176 mm**입니다. [제어와 보정](../control/README.md#전시-추적과-턱-시험) · [기록 필드](records/README.md#p01p08-실물-시험) · [턱 CAD 검사](../control/jaw-opening-check.json)

```sh
python control/pc/jaw_clack.py --serial /dev/ttyACM0 --drive
python control/pc/commission.py --serial /dev/ttyACM0 --release
```

전시 턱의 닫힘 복구를 확인할 때는 목과 턱을 받치고 토크를 해제합니다. 목 양축을 중립 ±11틱에 두고, 실측으로 확인한 무접촉 구간에서 턱을 닫힘 영점보다 12틱 넘게 엽니다(예: 확인된 범위 안의 31틱). 110틱은 펌웨어 복구 입력의 상한입니다. 모터 전원이 공급되고 토크 OFF인 상태에서 115200 bps 시리얼로 `READ 6`으로 시작 틱을 기록하고 `ARM_EXHIBIT`를 보냅니다. 2.4초 이내 `ARMED_EXHIBIT 31` 응답을 받고 `EXHIBIT_JAW_UNCALIBRATED`가 없는지 확인합니다. 응답 뒤 `CHECK 6`으로 보정 여부, `torque=1`, 닫힘 영점 기준 −5~+12틱 위치를 기록합니다. 복구 중에는 `HOLD`와 `RELEASE`로 중단할 수 있습니다. 시험이 끝나면 목과 턱을 받쳐 `RELEASE`와 `RELEASED`를 확인합니다. [전시 턱 복구](../control/README.md#전시-추적과-턱-시험)

### P07 카메라 왕복과 전원

P04 보정과 목 좌우 단독 구동을 마칩니다. 외장과 덮개를 닫고 전시에 사용할 PC·USB 연장선으로 연결합니다. 전시 해상도·프레임률로 UVC 영상을 연속 수신하면서 USB 접속 이벤트를 기록합니다. 시험 전후 Windows에서는 USBView의 High-Speed, Linux에서는 `lsusb -t`의 `480M`을 확인합니다. [카메라 접합과 조립 전 확인](../mechanical/revisions/b25/assembly.md#카메라-usb-선재)

1. 추적 프로그램을 닫고 목과 턱을 받쳐 토크를 해제합니다. 자동 반복 송신이 가능한 시리얼 도구를 115200 bps, 줄바꿈 사용으로 엽니다. `PING` → `R5B1 1`, `ARM 8` → `ARMED 8`을 확인합니다.
2. `GO 0 0 0 -60 0`과 `GO 0 0 0 60 0`은 ID4의 양쪽 보정 끝점입니다. 각 끝점까지 같은 `GO`를 약 100 ms마다 보냅니다. 송신 사이에 `READ 4`로 현재 위치를 읽습니다. `RAW 4`가 해당 보정 끝 틱의 8틱 이내에 들면 반대쪽으로 전환합니다. 400 ms 동안 `GO`가 없으면 현재 위치를 유지합니다.
3. 한쪽 → 반대쪽 → 원래 쪽을 완료해야 한 번입니다. 실제 끝점은 중립과 원시 틱의 차를 `360 / 4096`으로 환산해 왼쪽은 음수, 오른쪽은 양수로 기록합니다.
4. 반복 송신을 끄고 `HOLD`를 보냅니다. 목과 턱을 받친 채 `RELEASE` → `RELEASED`를 확인합니다. [보정과 한 축 구동](../control/README.md#보정과-한-축-구동) · [카메라 접합](../mechanical/revisions/b25/assembly.md#카메라-usb-선재)

왕복과 별도로 눈·목 추적과 깜빡임을 전시 설정에서, 턱 동작을 별도 시연 모드에서 확인합니다. 모터 기동·반전이 일어나는 동안에도 UVC 영상을 수신하며 영상 멈춤·프레임 손실, USB 끊김·재인식의 시각을 구동 기록과 함께 남깁니다. 구동 중 두 어댑터와 모터 단자의 최저·최고 전압을 기록합니다. 목 반복 구동 직후 전원을 분리하고 `12 V SERVICE` 커넥터 두 접합의 절연 표면 온도와 실내 온도를 기록합니다. [구동 중 전원 확인](../electronics/README.md#구동-중-전원-확인) · [전시 추적과 턱 시험](../control/README.md#전시-추적과-턱-시험)

전시 카메라 지연은 좌우 10°에 표시한 얼굴 이미지의 전환과 로봇 눈의 새 움직임을 같은 고속 영상으로 찍어 프레임 차이를 촬영 프레임률로 나눕니다. 눈이 멈춘 뒤 다음 전환을 반복하고, 카메라 해상도, 실측 프레임률과 지연 중앙값·최댓값을 기록합니다. 모형 입력 지연 `camera_latency_s`를 다시 잴 때는 얼굴 위치 변화에서 `Planner`가 새 관측을 받기까지 잽니다. [추적 모형](scenes.py)

OpenRB 재시작 시험은 **모터 전원을 켠 채** 진행합니다. 아래 `commission.py` 명령은 저장소 루트에서 `python control/pc/commission.py --serial /dev/ttyACM0` 뒤에 붙여 실행합니다. 포트는 실제 장치에 맞춥니다. [펌웨어 재시작 시험](../tests/test_firmware.py)

1. 목과 턱을 받칩니다. 확인을 마친 단독 구동 모드에서 토크를 켠 뒤 구동 프로그램을 닫거나 시리얼에서 `HOLD`를 보내고 포트를 비웁니다. `--check`로 재시작 전 ID 1–6의 `torque=`를 기록해 시험한 축의 토크가 1인지 확인합니다.
2. OpenRB만 재시작합니다. 새 구동이나 해제 명령 전에 `--check`로 `torque=`를 다시 기록합니다. `torque=1`인 축은 `CHECK`로 표시되며 명령의 종료값이 1일 수 있습니다. 응답이 없는 축은 미확인으로 기록합니다.
3. 목과 턱을 받친 채 `--release`를 실행합니다. `RELEASED`와 후속 `--check`의 전 축 `torque=0`을 확인합니다. 서보 전원 재투입 시의 시작 상태는 별도로 모터 전원을 껐다 켜고 새 구동이나 해제 명령 전에 확인합니다. [제어 오류와 해제](../control/README.md#구동-중-오류)

### P02 케이블 당김

전원을 끄고 받침을 고정합니다. 외부 전원·USB를 실제 사용 배치에 연결하고 카메라 USB-A 쪽 고정까지 끝냅니다. 케이스가 없다면 전시 받침대에 고정한 지지대에 타이를 달아 피복을 잡습니다. 고정점 직전의 피복과 옆 고정면에 기준선을 표시합니다. 힘 게이지로 외부 케이블 피복을 직선과 45°에서 각각 **10 N, 30초** 당깁니다. 당기는 동안 최대 미끄러짐을 0.1 mm 단위로 읽고 피복 눌림과 손상을 확인합니다. 이동 **0.5 mm 이하**와 피복 상태를 케이블별로 기록합니다. 이는 조립된 케이블 고정 시험입니다. 보호 케이스 모델의 1 N 접촉 조건은 별도입니다. [B22 배선과 받침대 고정점](../mechanical/revisions/b22/README.md#배선)

### P03 깜빡임

보정한 뒤 목을 중립에 받치고 `python control/pc/track.py --source 0 --serial /dev/ttyACM0 --drive --axes blink`로 깜빡임만 켭니다. 사람 얼굴을 시야에 두고 연속 50회를 촬영해 눈꺼풀이나 링크가 걸리는지 봅니다. 이동을 0°~90°로 환산해 닫히며 5°를 지난 시점부터 다시 열려 5°를 지날 때까지 잽니다. 닫히는 시간은 5°→85°, 여는 시간은 85°→5°입니다. 전체 **0.8~1.5초**, 연속 깜빡임 시작점의 간격 **4~10초**인지 확인합니다. `P03.json`에 완료 횟수 `cycles`와 걸린 횟수 `binding_events`를 정수로 적습니다. 합격 조건은 50회 이상과 걸림 0회입니다. [구동 보정](../control/README.md)

### P04 목 좌우 떨림

모든 체결과 보정을 마친 뒤 눈과 목 추적을 켭니다. 목을 보정된 한쪽 끝에서 반대쪽 끝까지 10회 움직입니다. 옆에서 영상을 찍어 끝에서 떨림이나 받침이 들리는 현상이 있는지 확인합니다. 보정된 양 끝 각도와 떨림이 보인 횟수를 기록합니다.

S01을 실물에서 확인할 때는 목을 정면에 두고, 앞 1.5 m에 표시한 선을 0.8 m/s로 양방향에서 지나갑니다. 대상 방향과 눈·목 움직임을 같은 시각 기준으로 기록합니다. 카메라 시야 진입부터 시선이 10° 안에 들어올 때까지의 시간, 그때부터 반대쪽 80°까지의 시선 성공률과 목 최고 속도를 잽니다. 추적 중 얼굴을 가리는 별도 반복으로 마지막 자세 유지 시간과 정면 복귀 속도를 확인합니다. [S01 판정 기준](requirements.md#동작-장면) · [구동 범위](../control/README.md)

### P05 위를 보는 설치 자세

받침을 수평으로 고정하고 로봇의 중립 동공 중심이 바닥에서 **1.4 m**인지 잽니다. 수평으로 1.0 m 앞에 사람의 눈 중심을 **1.6 m**로 둡니다. 두 눈높이로 계산한 필요한 상향각은 약 11.3°입니다. 옆 영상에서 안구 중심과 동공 중심을 잇는 선을 그어 얼굴 눈높이에 닿는지 확인합니다. 설치 높이, 받침 각도와 실제 동공 방향을 기록합니다. [B22 CAD](../mechanical/revisions/b22/R5-B22-Assembly.FCStd)

### P06 턱 움직임

보정 후 목을 중립에 받치고 아래 명령으로 턱을 두 번 열고 닫습니다. 앞에서 짧게 열렸다 닫히는 움직임과 앞니 사이 벌어짐을 촬영합니다. B22의 최대 명령은 5.5°이고 소리는 선택입니다. 시험이 끝나면 목을 받친 채 `python control/pc/commission.py --serial /dev/ttyACM0 --release`를 실행합니다. [턱 시험과 해제 절차](../control/README.md)

```sh
python control/pc/jaw_clack.py --serial /dev/ttyACM0 --drive
```

B24 전시 턱의 냉간 복구 검사 절차입니다. 위치 P 게인은 1000입니다. 전원을 분리하고 목을 중립에서 양쪽 최대 11틱에 받친 뒤, 턱을 검증된 열린 범위 안에서 최대 110틱까지 준비합니다. USB 시리얼에서 `ARM_EXHIBIT`를 보내고 시간 기록이 있는 응답을 저장합니다. `ARM_EXHIBIT` 발행부터 `ARMED_EXHIBIT 31`까지 걸린 시간과 ID6의 위치를 기록합니다. 응답이 없거나 복구가 2.4초를 넘으면 실패입니다. `EXHIBIT_JAW_UNCALIBRATED` 없이 ID6 보정과 토크가 모두 켜져 있어야 복구 성공으로 기록합니다. 복구 중 위치는 따로 동기화한 위치 계측으로 기록합니다. 복구 도중에는 `HOLD`와 `RELEASE`가 즉시 중단을 요청합니다. USB 출력은 복구 결과에서 재개하므로 `CHECK 6`은 결과가 나간 뒤에 보냅니다. 기한 시험은 USB 호스트의 읽기가 멈춘 경우에도 반복하고, ID6의 첫 토크 OFF 패킷과 실제 해제 확인 시각을 각각 기록합니다. 조립된 모터 단자의 최소 부하 전압 조건을 포함해 반복합니다. 목표값은 보정 영점 이내여야 하며 실제 치아 간격은 닫힘 중에도 0.5 mm 이상이어야 합니다.

목을 받친 뒤 `RELEASE`의 결과를 확인하고 포트를 닫습니다. 그다음 `python control/pc/track.py --source 0 --serial /dev/ttyACM0 --drive`로 전시 추적 중 턱을 영상으로 기록합니다. 보정 영점 대비 정지 위치와 지속 떨림 여부, 시험 시간과 시험 전후 모터 온도를 남깁니다.

### P07 카메라 지연 실측

보정 후 실제 전시용 카메라와 전체 축 설정으로 구동합니다. 카메라 중심에서 왼쪽 10°와 오른쪽 10°에 같은 얼굴 이미지를 번갈아 표시합니다. 화면과 로봇 눈을 **한 영상에 240 fps**로 찍습니다. 매번 눈이 멈춘 뒤 화면을 바꿉니다. 화면이 바뀐 프레임과 새 방향의 움직임이 두 프레임 연속 보이기 시작한 첫 프레임의 번호 차이를 240으로 나눕니다. 카메라 해상도와 실제 프레임률, 10회 지연의 중앙값과 최댓값을 기록합니다.

이 값은 얼굴 위치 변화부터 눈이 움직이기 시작할 때까지의 지연입니다. 자동 검사의 `camera_latency_s`는 `Planner`에 입력이 도착하기 전의 지연을 뜻하고, 검사는 이후 명령 주기와 모터 움직임을 별도로 계산합니다. 자동 검사 값을 갱신할 때는 얼굴 위치 변화부터 `Planner`가 바뀐 관측을 받은 시각까지를 잽니다. [추적 모형](scenes.py)

### P08 전체 조립과 정비 접근

실제 출력물과 구매품으로 배선과 모든 체결을 끝까지 조립합니다. 전원을 끄고 뒤쪽 케이블 덮개와 하부 보드 덮개의 나사를 각각 전부 뺍니다. 두 덮개를 다시 닫을 때까지 너트가 제자리에 남는지 확인합니다. 일반 육각렌치와 스패너·소켓으로 체결부에 닿는지, 케이블이 눌리지 않고 커넥터가 끝까지 들어가는지도 봅니다.

`P08.json`에 사용한 공구와 걸림이 있었던 단계를 기록합니다. 합격 기록에는 전체 조립 완료 `full_assembly: true`, 절차서에 없던 추가 가공 횟수 `unplanned_rework_count: 0`, 너트가 남은 덮개 목록 `retained_nut_covers: ["rear-cable", "bottom-board"]`를 적습니다. B24의 목 체결부는 조립에 앞서 양방향 하중 및 유격 시험도 수행합니다. [B24 조립 순서](../mechanical/revisions/b24/assembly.md) · [목 체결부 시험](../mechanical/revisions/b24/pitch-coupler.md)
