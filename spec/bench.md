# R5 실물 시험

시험한 리비전과 CAD SHA-256, 날짜, 사용한 부품과 실측값을 해당 시험의 `records/P0x.json`에 기록합니다. 리비전별 판 배치, 홀 마감과 공구는 해당 조립 자료를 따릅니다. P03에서는 눈꺼풀 ID3 단자의 구동 중 전압도 함께 기록합니다. [합격 기준](requirements.md) · [기록 형식](records/README.md) · [B24 조립 자료](../mechanical/revisions/b24/assembly.md)

B22 보호 케이스는 별도 선택품입니다. 접촉 검수는 보호 케이스를 실제로 설치한 상태에서 시행합니다.

## P01 끼움과 홀 맞춤

최종 [B22 3MF](../mechanical/revisions/b22/R5-B22-P2S.3mf)를 P2S, 0.4 mm 노즐, 0.20 mm 층, 텍스처 PEI, PETG HF 설정으로 엽니다. 아래 시간과 질량은 판 전체를 출력하는 예상치입니다. 8·9·12번 판부터 출력하면 회전판, 턱 받침, 코 브래킷을 약 **5시간 45분, 80.3 g**으로 먼저 확인할 수 있습니다. 나머지 결합은 표의 해당 부품이 준비된 뒤 검사합니다. [B22 슬라이싱 결과](../mechanical/revisions/b22/slicing-check.json) · [3번 판 슬라이싱 결과](../mechanical/revisions/b21/slicing-check.json)

## P02 케이블 당김

전원을 끄고 받침을 고정합니다. 외부 전원·USB를 실제 사용 배치에 연결하고 카메라 USB-A 쪽 고정까지 끝냅니다. 케이스가 없다면 전시 받침대에 고정한 지지대에 타이를 달아 피복을 잡습니다. 고정점 직전의 피복과 옆 고정면에 기준선을 표시합니다. 힘 게이지로 외부 케이블 피복을 직선과 45°에서 각각 **10 N, 30초** 당깁니다. 당기는 동안 최대 미끄러짐을 0.1 mm 단위로 읽고 피복 눌림과 손상을 확인합니다. 이동 **0.5 mm 이하**와 피복 상태를 케이블별로 기록합니다. 이는 조립된 케이블 고정 시험입니다. 보호 케이스 모델의 1 N 접촉 조건은 별도입니다. [B22 배선과 받침대 고정점](../mechanical/revisions/b22/README.md#배선)

## P03 깜빡임

보정한 뒤 목을 중립에 받치고 `python control/pc/track.py --source 0 --serial /dev/ttyACM0 --drive --axes blink`로 깜빡임만 켭니다. 사람 얼굴을 시야에 두고 연속 50회를 촬영해 눈꺼풀이나 링크가 걸리는지 봅니다. 이동을 0°~90°로 환산해 닫히며 5°를 지난 시점부터 다시 열려 5°를 지날 때까지 잽니다. 닫히는 시간은 5°→85°, 여는 시간은 85°→5°입니다. 전체 **0.8~1.5초**, 연속 깜빡임 시작점의 간격 **4~10초**인지 확인합니다. `P03.json`에 완료 횟수 `cycles`와 걸린 횟수 `binding_events`를 정수로 적습니다. 합격 조건은 50회 이상과 걸림 0회입니다. [구동 보정](../control/README.md)

## P04 목 좌우 떨림

모든 체결과 보정을 마친 뒤 눈과 목 추적을 켭니다. 목을 보정된 한쪽 끝에서 반대쪽 끝까지 10회 움직입니다. 옆에서 영상을 찍어 끝에서 떨림이나 받침이 들리는 현상이 있는지 확인합니다. 보정된 양 끝 각도와 떨림이 보인 횟수를 기록합니다.

S01을 실물에서 확인할 때는 목을 정면에 두고, 앞 1.5 m에 표시한 선을 0.8 m/s로 양방향에서 지나갑니다. 대상 방향과 눈·목 움직임을 같은 시각 기준으로 기록합니다. 카메라 시야 진입부터 시선이 10° 안에 들어올 때까지의 시간, 그때부터 반대쪽 80°까지의 시선 성공률과 목 최고 속도를 잽니다. 추적 중 얼굴을 가리는 별도 반복으로 마지막 자세 유지 시간과 정면 복귀 속도를 확인합니다. [S01 판정 기준](requirements.md#동작-장면) · [구동 범위](../control/README.md)

## P05 위를 보는 설치 자세

받침을 수평으로 고정하고 로봇의 중립 동공 중심이 바닥에서 **1.4 m**인지 잽니다. 수평으로 1.0 m 앞에 사람의 눈 중심을 **1.6 m**로 둡니다. 두 눈높이로 계산한 필요한 상향각은 약 11.3°입니다. 옆 영상에서 안구 중심과 동공 중심을 잇는 선을 그어 얼굴 눈높이에 닿는지 확인합니다. 설치 높이, 받침 각도와 실제 동공 방향을 기록합니다. [B22 CAD](../mechanical/revisions/b22/R5-B22-Assembly.FCStd)

## P06 턱 움직임

보정 후 목을 중립에 받치고 아래 명령으로 턱을 두 번 열고 닫습니다. 앞에서 짧게 열렸다 닫히는 움직임과 앞니 사이 벌어짐을 촬영합니다. B22의 최대 명령은 5.5°이고 소리는 선택입니다. 시험이 끝나면 목을 받친 채 `python control/pc/commission.py --serial /dev/ttyACM0 --release`를 실행합니다. [턱 시험과 해제 절차](../control/README.md)

```sh
python control/pc/jaw_clack.py --serial /dev/ttyACM0 --drive
```

B24 이후에는 P 게인 1000을 쓰는 전시 턱의 냉간 복구도 검사합니다. 전원을 분리하고 목을 중립에서 양쪽 최대 11틱에 받친 뒤, 턱을 검증된 열린 범위 안에서 최대 110틱까지 준비합니다. USB 시리얼에서 `ARM_EXHIBIT`를 보내고 시간 기록이 있는 응답을 저장합니다. `ARM_EXHIBIT` 발행부터 `ARMED_EXHIBIT 31`까지 걸린 시간과 ID6의 위치를 기록합니다. 응답이 없거나 복구가 2.4초를 넘으면 실패입니다. `EXHIBIT_JAW_UNCALIBRATED` 없이 ID6 보정과 토크가 모두 켜져 있어야 복구 성공으로 기록합니다. 턱 위치가 포함되지 않는 `STATE` 대신 `CHECK 6` 응답이나 동기화한 모터 위치 계측을 사용합니다. 조립된 모터 단자의 최소 부하 전압 조건을 포함해 반복합니다. 목표값은 보정 영점 이내여야 하며 실제 치아 간격은 닫힘 중에도 0.5 mm 이상이어야 합니다.

목을 받친 뒤 `RELEASE`의 결과를 확인하고 포트를 닫습니다. 그다음 `python control/pc/track.py --source 0 --serial /dev/ttyACM0 --drive`로 전시 추적 중 턱을 영상으로 기록합니다. 보정 영점 대비 정지 위치와 지속 떨림 여부, 시험 시간과 시험 전후 모터 온도를 남깁니다.

## P07 카메라 지연 실측

보정 후 실제 전시용 카메라와 전체 축 설정으로 구동합니다. 카메라 중심에서 왼쪽 10°와 오른쪽 10°에 같은 얼굴 이미지를 번갈아 표시합니다. 화면과 로봇 눈을 **한 영상에 240 fps**로 찍습니다. 매번 눈이 멈춘 뒤 화면을 바꿉니다. 화면이 바뀐 프레임과 새 방향의 움직임이 두 프레임 연속 보이기 시작한 첫 프레임의 번호 차이를 240으로 나눕니다. 카메라 해상도와 실제 프레임률, 10회 지연의 중앙값과 최댓값을 기록합니다.

이 값은 얼굴 위치 변화부터 눈이 움직이기 시작할 때까지의 지연입니다. 자동 검사의 `camera_latency_s`는 `Planner`에 입력이 도착하기 전의 지연을 뜻하고, 검사는 이후 명령 주기와 모터 움직임을 별도로 계산합니다. 자동 검사 값을 갱신할 때는 얼굴 위치 변화부터 `Planner`가 바뀐 관측을 받은 시각까지를 잽니다. [추적 모형](scenes.py)

## P08 전체 조립과 정비 접근

실제 출력물과 구매품으로 배선과 모든 체결을 끝까지 조립합니다. 전원을 끄고 뒤쪽 케이블 덮개와 하부 보드 덮개의 나사를 각각 전부 뺍니다. 두 덮개를 다시 닫을 때까지 너트가 제자리에 남는지 확인합니다. 일반 육각렌치와 스패너·소켓으로 체결부에 닿는지, 케이블이 눌리지 않고 커넥터가 끝까지 들어가는지도 봅니다.

`P08.json`에 사용한 공구와 걸림이 있었던 단계를 기록합니다. 합격 기록에는 전체 조립 완료 `full_assembly: true`, 절차서에 없던 추가 가공 횟수 `unplanned_rework_count: 0`, 너트가 남은 덮개 목록 `retained_nut_covers: ["rear-cable", "bottom-board"]`를 적습니다. B24의 목 체결부는 조립에 앞서 양방향 하중 및 유격 시험도 수행합니다. [B24 조립 순서](../mechanical/revisions/b24/assembly.md) · [목 체결부 시험](../mechanical/revisions/b24/pitch-coupler.md)
