# B22 실물 시험

시험한 B22 버전, 날짜, 사용한 부품과 실측값을 해당 시험의 `records/P0x.json`에 사람이 기록합니다. [합격 기준](requirements.md) · [기록 형식](records/README.md)

## P01 끼움과 홀 맞춤

최종 [B22 3MF](../mechanical/revisions/b22/R5-B22-P2S.3mf)를 P2S, 0.4 mm 노즐, 0.20 mm 층, 텍스처 PEI, PETG HF 설정으로 엽니다. 아래 시간과 질량은 판 전체를 출력하는 예상치입니다. 8·9·12번 판부터 출력하면 회전판, 턱 받침, 코 브래킷을 약 **5시간 45분, 80.3 g**으로 먼저 확인할 수 있습니다. 나머지 결합은 표의 해당 부품이 준비된 뒤 검사합니다. [B22 슬라이싱 결과](../mechanical/revisions/b22/slicing-check.json) · [3번 판 슬라이싱 결과](../mechanical/revisions/b21/slicing-check.json)

## P02 케이블 당김

전원을 끄고 받침을 고정합니다. 외부 전원·USB를 실제 사용 배치에 연결하고 카메라 USB-A 쪽 고정까지 끝냅니다. 고정점 직전의 피복과 옆 고정면에 기준선을 표시합니다. 힘 게이지로 외부 케이블 피복을 직선과 45°에서 각각 **10 N, 30초** 당깁니다. 당기는 동안 최대 미끄러짐을 0.1 mm 단위로 읽고 피복 눌림과 손상을 확인합니다. 이동 **0.5 mm 이하**와 피복 상태를 케이블별로 기록합니다. 이는 조립된 케이블 고정 시험입니다. 보호 케이스 모델의 1 N 접촉 조건은 별도입니다. [B22 배선 순서](../mechanical/revisions/b22/assembly.md)

## P03 깜빡임

보정한 뒤 목을 중립에 받치고 `python control/pc/track.py --source 0 --serial /dev/ttyACM0 --drive --axes blink`로 깜빡임만 켭니다. 사람 얼굴을 시야에 두고 연속 50회를 촬영해 닫힐 때의 소리와 링크 헐거워짐을 확인합니다. 이동을 0°~90°로 환산해 전체는 닫히며 5°를 지난 시점부터 다시 열려 5°를 지날 때까지 잽니다. 닫히는 시간은 5°→85°, 여는 시간은 85°→5°입니다. 전체 **0.3~0.6초**, 닫는 시간이 여는 시간 이하인지를 기록합니다. [구동 보정](../control/README.md)

## P04 목 좌우 떨림

모든 체결과 보정을 마친 뒤 S01을 만족하는 추적 설정으로 얼굴을 좌우로 이동시켜, 목을 보정된 한쪽 끝에서 반대쪽 끝까지 10회 움직입니다. 옆에서 영상을 찍어 끝에서 떨림이나 받침이 들리는 현상이 있는지 확인합니다. 보정된 양 끝 각도와 떨림이 보인 횟수를 기록합니다. [구동 범위](../control/README.md)

## P05 위를 보는 설치 자세

받침 앞쪽을 들어 바닥이 수평보다 10° 위로 기울도록 고정하고 경사계로 확인합니다. 눈 중심 높이 1.0 m에서 수평으로 1.0 m 앞, 높이 1.6 m에 얼굴을 둡니다. 필요한 상향각은 약 31°입니다. 옆 영상에서 안구 중심과 동공 중심을 잇는 선을 그어 얼굴 눈높이에 닿는지 확인합니다. 받침과 명령 각도를 합하면 33°이고, B22 CAD의 중립 동공은 약 5.2° 아래를 향합니다. 받침 각도와 실제 동공의 최대 상향각을 따로 기록합니다. [B22 CAD](../mechanical/revisions/b22/R5-B22-Assembly.FCStd)

## P06 턱 소리와 모양

보정 후 목을 중립에 받치고 아래 명령으로 턱을 두 번 열고 닫습니다. 앞에서 소리와 앞니 사이 벌어짐을 촬영합니다. B22의 최대 명령은 5.5°이고, 소리와 모양의 합격은 사람이 판단합니다. 시험이 끝나면 목을 받친 채 `python control/pc/commission.py --serial /dev/ttyACM0 --release`를 실행합니다. [턱 시험과 해제 절차](../control/README.md)

```sh
python control/pc/jaw_clack.py --serial /dev/ttyACM0 --drive
```

## P07 카메라 지연 실측

목을 중립에 받치고 `--axes eye-yaw`로 눈 좌우만 켭니다. 카메라 중심에서 왼쪽 10°와 오른쪽 10°에 같은 얼굴 이미지를 번갈아 표시합니다. 화면과 로봇 눈을 **한 영상에 240 fps**로 찍습니다. 매번 눈이 멈춘 뒤 화면을 바꿉니다. 화면이 바뀐 프레임과 새 방향의 움직임이 두 프레임 연속 보이기 시작한 첫 프레임의 번호 차이를 240으로 나눕니다. 카메라 해상도와 실제 프레임률, 10회 지연의 중앙값과 최댓값을 기록합니다.

이 값은 얼굴 위치 변화부터 눈이 움직이기 시작할 때까지의 지연입니다. 자동 검사의 `camera_latency_s`는 `Planner`에 입력이 도착하기 전의 지연을 뜻하고, 검사는 이후 명령 주기와 모터 움직임을 별도로 계산합니다. 자동 검사 값을 갱신할 때는 얼굴 위치 변화부터 `Planner`가 바뀐 관측을 받은 시각까지를 잽니다. [추적 모형](scenes.py)
