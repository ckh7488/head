# R5 B22 인수 기준

사용 장면을 먼저 정하고 구동, 조립, 실물 결과를 각각 확인합니다. 수치 기준은 [criteria.toml](criteria.toml)에 있습니다.

```sh
python spec/verify.py
```

Python 3.11 이상에서 실행합니다. 종료값은 전부 통과하면 0, 미달 항목이 있으면 1, 미달 없이 검증이 남으면 2입니다. 검사 대상은 B22 릴리스입니다. 형상을 수정하면 해당 검사와 실물 기록을 새 CAD 기준으로 갱신합니다.

## 동작 장면

| ID | 합격 기준 |
| --- | --- |
| S01 | 0.8 m 앞을 1.2 m/s로 지나가는 사람을 좌우 80° 구간에서 놓치지 않습니다. 평가 시간의 90% 이상 눈 방향이 사람에게서 10° 이내입니다. |
| S01b | 옆 40°의 사람에게 고개를 돌릴 때 목이 목표를 12° 넘게 지나치지 않고, 정지 후 시선 오차가 2° 이하입니다. |
| S02 | 눈 높이 1.0 m인 장치를 10° 올려 두고, 앞 1 m에 선 눈 높이 1.6 m인 사람을 봅니다. 명령 각도와 실제 동공 방향을 구분하고, 설치 상태를 P05로 확인합니다. |
| S03 | 한 번의 깜빡임은 0.30~0.60초이고 닫는 시간이 여는 시간 이하입니다. 실제 눈꺼풀과 소리는 P03으로 확인합니다. |
| S04 | 턱의 열림과 소리가 자연스럽습니다. P06의 실물 판정을 사용합니다. |
| S05 | 조립 순서대로 부품과 공구를 넣을 수 있습니다. C01~C04와 P01을 모두 확인합니다. |
| S06 | M3 원통머리, 일반 육각너트와 평와셔를 기본으로 합니다. 구매품 나사산·홀과 핀 이탈 방지용 무두나사는 명시된 위치에서 예외로 둡니다. 케이스의 일반 M3 육각너트는 ISO 4032를 사용합니다. |

추적 모델은 현재 PC Planner와 펌웨어의 구동 설정을 사용합니다. 카메라 화각 106°와 영상 지연 120 ms는 가정값입니다. S01은 초안의 검사대로 출발 쪽에 목을 미리 맞춘 상태를 판정하고, 정면 대기에서 시작하는 경우도 진단값으로 출력합니다. S01b는 모델의 수평 중심선 오차를 검사합니다. 렌즈와 전체 왕복 지연은 [실물 시험](bench.md)에서 재확인합니다.

## 조립과 움직임

| ID | 합격 기준 |
| --- | --- |
| C01 | 지정 구동 범위에서 움직이는 부품, 체결품과 배선이 간섭하지 않습니다. 검사한 자세와 연속으로 보장된 구간을 기록합니다. |
| C02 | 조립 순서에 포함된 부품을 넣는 경로가 열려 있습니다. B22의 136단계와 별도 삽입 증거를 사용합니다. |
| C03 | 조립 상태에 맞는 육각렌치와 스패너·소켓 경로가 있습니다. 함께 넣어야 하는 공구는 동시에 확인합니다. |
| C04 | 제조·조립 오차가 겹쳐도 간섭하지 않습니다. 검사한 조인트와 방향별 오차, 남은 최소 여유를 기록합니다. |

[M01~M09 기구 기준](mechanisms.md)은 힘이 전달되는 경로를 확인합니다. 각 부위에서 적용할 조건과 측정 근거를 기록합니다. [P01~P07 실물 시험](bench.md)은 해당 CAD와 동일한 실물로 시행합니다. 기록 형식은 [records](records/)에 있습니다.

실물에서 새 문제가 나오면 관찰 결과와 재현 조건을 남기고, 다음 설계에서 같은 문제가 걸리도록 측정 가능한 검사로 추가합니다.
