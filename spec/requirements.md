# R5 인수 기준

사용 장면을 먼저 정하고 구동, 조립, 실물 결과를 각각 확인합니다. 수치 기준은 [criteria.toml](criteria.toml)에 있습니다.

```sh
python spec/verify.py
```

Python 3.11 이상에서 실행합니다. 종료값은 전부 통과하면 0, 미달 항목이 있으면 1, 미달 없이 검증이 남으면 2입니다. 위 명령은 B22 기록에 연결됩니다. B24 CAD·출력판·펌웨어의 디지털 결과는 B24 검증 명령으로 확인하고, 실물 기록에는 해당 CAD 리비전을 씁니다. [B24 검증](../mechanical/revisions/b24/#파일과-검사-재현)

## 동작 장면

| ID | 합격 기준 |
| --- | --- |
| S01 | 정면으로 대기하다가 1.5 m 앞을 0.8 m/s로 지나가는 사람을 눈과 목으로 따라봅니다. |
| S01b | 옆 40°의 사람에게 고개를 돌릴 때 목이 목표를 12° 넘게 지나치지 않고, 정지 후 시선 오차가 10° 이하입니다. |
| S02 | 받침을 수평으로 놓고 로봇 눈을 바닥에서 1.4 m에 맞춥니다. 앞 1 m에 선 눈 높이 1.6 m인 사람을 볼 수 있는지 실제 동공 방향과 P05로 확인합니다. |
| S03 | 깜빡임 한 번은 0.8~1.5초이고 시작 간격은 4~10초입니다. 눈꺼풀이 50회 연속 걸림 없이 움직이는지 P03에서 봅니다. |
| S04 | 목을 중립에 둔 상태에서 턱의 짧은 열림과 닫힘을 P06에서 봅니다. 소리는 선택입니다. 추적 중 간헐적인 턱 구동은 별도 검증 후 사용합니다. |
| S05 | 정해진 순서와 공구로 끝까지 조립하고, 뒤쪽 케이블 덮개와 하부 보드 덮개의 나사를 전부 빼도 너트가 남습니다. C01~C04, P01 및 P08을 확인합니다. |
| S06 | M3 원통머리, 일반 육각너트와 평와셔를 기본으로 합니다. 구매품 나사산·홀과 핀 이탈 방지용 무두나사는 명시된 위치에서 예외로 둡니다. 판정은 본체를 기준으로 합니다. |

S01은 아래 조건을 모두 확인합니다.

- 대상이 카메라 시야에 처음 들어온 프레임부터 1초 이내에 시선 오차가 10° 이하로 들어옵니다.
- 시선이 처음 10° 이내에 들어온 순간부터 대상이 반대쪽 80°에 닿을 때까지 평가합니다. 시야에서 벗어나는 구간도 평가 시간에 포함하며, 전체의 85% 이상에서 시선 오차가 10° 이하입니다.
- 추적 중 목 속도는 초당 45° 이하입니다. 얼굴을 놓치면 마지막으로 보던 방향을 2~3초 응시한 뒤 초당 15° 이하로 정면에 돌아옵니다. 새 얼굴이 보이면 눈이 먼저 그쪽으로 움직이고, 목이 이어서 따라갑니다.

추적 모델은 PC 제어와 펌웨어의 구동 설정을 사용합니다. 수평 화각 106°와 영상 지연 120 ms는 모형의 가정값입니다. S01b는 수평 시선 오차를 검사합니다. 렌즈와 전체 왕복 지연은 [실물 시험](bench.md)에서 확인합니다.

## 조립과 움직임

| ID | 합격 기준 |
| --- | --- |
| C01 | 지정 구동 범위에서 움직이는 부품, 체결품과 배선이 간섭하지 않습니다. 검사한 자세와 연속으로 보장된 구간을 기록합니다. |
| C02 | 조립 순서에 포함된 부품을 넣는 경로가 열려 있습니다. 검수할 리비전의 전체 조립 기록과 별도 삽입 증거를 사용합니다. [B23 조립](../mechanical/revisions/b23/assembly.md) · [B22 조립](../mechanical/revisions/b22/assembly.md) |
| C03 | 조립 상태에 맞는 육각렌치와 스패너·소켓 경로가 있습니다. 함께 넣어야 하는 공구는 동시에 확인합니다. |
| C04 | 제조·조립 오차가 겹쳐도 간섭하지 않습니다. 검사한 조인트와 방향별 오차, 남은 최소 여유를 기록합니다. |

[M01~M09 기구 기준](mechanisms.md)은 힘이 전달되는 경로를 확인합니다. M07에서 눈꺼풀 링크의 힘 전달각이 40° 미만이면 모형의 최대 요구 토크가 해당 모터 정지 토크의 20% 이하이고 P03 실물 50회에서 걸림이 0회일 때 예외를 인정합니다. [P01~P08 실물 시험](bench.md)은 해당 CAD와 동일한 실물로 시행합니다. 기록 형식은 [records](records/)에 있습니다.

실물에서 새 문제가 나오면 관찰 결과와 재현 조건을 남기고, 다음 설계에서 같은 문제가 걸리도록 측정 가능한 검사로 추가합니다.
