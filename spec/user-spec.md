# 1층 스펙: 사람 요구사항 (User Spec)

> **문서 역할 (2층 구조의 1층)**
> - **1층 (`user-spec.md`, 이 문서)**: 제작자(사람)가 원하는 **동작·환경·예산·제작 방식**을 일상 언어로 적습니다. **사람만 결정·수정합니다.**
> - **2층 ([conditions.md](conditions.md) · [requirements.md](requirements.md) · [criteria.toml](criteria.toml))**: AI가 1층을 만족시키기 위해 번역한 **CAD·기구·전장·3D 프린트 수치 기준**입니다.

---

## 1. 무엇을 하는 로봇인가 (원하는 동작)

- **시선 추적**: 탁자 위(눈 높이 약 1.4 m)에 놓인 해골 로봇이 앞을 **천천히 걸어 지나가는 사람**을 코에 숨긴 카메라로 찾아, **눈이 먼저 움직이고 목이 자연스럽게 따라가며** 쳐다본다.
- **눈 깜빡임**: 가만히 있거나 쳐다보는 동안 몇 초마다 한 번씩 자연스럽게 눈꺼풀을 깜빡인다.
- **턱 움직임**: 입을 벌릴 때 턱 끝이 눈으로 확실히 내려가는 게 보인다(소리는 선택).
- **겉모습과 크기**: 사람 해골처럼 그럴싸해 보이면 된다. **내부 부품이 빡빡하면 머리 크기를 적당히 키워도 된다**(정확한 실물 인체 비율을 고집하지 않는다).

## 2. 어디서 어떻게 쓰나 (사용 환경·내구성)

- **장소·온도**: 한국 일반 실내(**0~35 °C**, 겨울 비난방 실내 1 °C 하강과 여름 실내·모터 발열 포함), 평평한 바닥, 비·직사광선·심한 진동 없음.
- **사람 접촉**: 평소엔 손대지 않고 전시·동작하지만, 사람이 머리나 겉면을 **손으로 가볍게 툭 건드리거나 약하게 누르는 정도**에는 부러지거나 부품이 빠지지 않아야 한다.
- **전원·제어**: 일반 가정용 콘센트 어댑터 + PC 연결(USB 카메라 + OpenRB-150)로 동작한다.

## 3. 예산·제작·조립 제약 (사람의 현실 조건)

- **예산 절감 중요**: 불필요한 고가 부품·다회 재출력을 피한다.
- **3D 프린팅 1회 출력 우선**: 프린트샵(또는 대행)에 여러 번 왔다갔다하기 어렵다. **한 번에 일괄 출력**해서 집에서 간단한 수공구(드릴·사포·접착제·시임)로 맞춰 조립할 수 있어야 한다.
- **조립·정비 난이도**: 특수 공구 없이 일반 육각렌치·스패너·인두기 수준으로 조립 가능해야 한다. 고난이도 SMD 손리플로우(0.65 mm 피치 등)는 피하고 공장 실장(PCBA)이나 기성 모듈을 우선한다.

## 4. 애매한 경계 합의표 (사람 ↔ AI 상의해서 닫은 기준)

사람은 모터 속도나 CAD 치수를 모르므로, 넓게 말한 요구사항을 AI가 현실적인 숫자로 닫을 때 **아래처럼 사람과 상의해 확정**합니다.

| 사람이 말한 요구 | 애매한 지점 (그대로 두면 박살 나는 이유) | 상의해서 닫은 현실 기준 (2층으로 전달) |
| --- | --- | --- |
| 지나가는 사람을 따라본다 | 뛰는 사람(5 m/s)까지 쫓으려면 대형 산업용 모터가 필요 | **1.5 m 앞을 천천히 걷는 사람(0.8 m/s)**, 1초 내 포착, 시선 오차 10° 이내 |
| 사람이 약하게 치는 건 버틴다 | "약하게"가 500 g인지 주먹질(50 N)인지에 따라 구조가 완전히 달라짐 | **5 N (약 500 g 무게로 누르는 힘)**에 파손·이탈 없음 (강한 충격은 아크릴 커버 등으로 대응) |
| 크기는 적당히 그럴싸하면 된다 | 크기를 고정 상수로 착각하면 0.3 mm 공차 싸움·무한 수정에 빠짐 | **B25는 현재 크기 유지, 신규 설계(V2)는 내부가 좁으면 15~25% 확대 허용** |
| 프린팅 여러 번 안 가고 한 번에 뽑기 | 0.05 mm 끼워맞춤을 출력만으로 맞추려 하면 2~3회 방문 필수 | **중간 보정 치수 1회 일괄 출력 + 집에서 드릴·사포·시임·에폭시 마감** |
| 실내에서 쓴다 | 15~30 °C로 가정하면 한국 겨울 실내(1 °C)에서 일반 PLA가 깨질 수 있음 | **0~35 °C 기준, Bambu PETG HF(건조 필수)** 단일 재질 통일 |
| 오래 돌려도 선이 안 끊긴다 | 10만 회 내구 시험은 개인이 불가 | **100회 연속 왕복 확인**(장기 전시 투입 전 1,000회 권장) |

## 5. AI와의 협업 규칙 (무한 수정 방지 프로토콜)

AI는 2층 스펙([conditions.md](conditions.md))을 설계·검토할 때 아래 규칙을 반드시 지킵니다.

1. **임의 상향·추측 금지**: 1층에 없는 가혹한 조건을 AI가 혼자 추가하지 않는다.
2. **애매하면 숫자를 만들어 묻기**: 1층 표현이 애매해 설계가 갈릴 때는 혼자 추측하지 말고, **"옵션 A(기본·저비용) vs 옵션 B(고성능·비용 증가)"** 2~3개 선택지와 트레이드오프를 쉬운 말로 제시해 사람에게 결정받고 **4절 표에 기록**한다.
3. **2층에서 막히면 1층으로 올라오기**: 2층의 공차·벽 두께·크기 제약이 서로 충돌해 국소 수정이 반복되면, 혼자 0.1 mm씩 깎지 말고 **"크기를 키울까요 / 기능을 줄일까요 / 이 부위만 예외로 둘까요?"**를 사람에게 먼저 묻는다.
4. **가상 검토 종료선**: 1층 요구사항과 2층 기준을 모두 통과하면 가상 검토를 멈추고 실물 출력·조립으로 넘어간다.
