# R5 검토와 판정 절차

B25의 합격 조건은 [고정 검사 조건](conditions.md)에 있습니다. 이 문서는 그 조건을 적용해 판정과 근거를 남기는 절차입니다.

## B25 검토 순서

1. 저장소의 B25 CAD·P2S 출력본, A5 배선과 펌웨어를 맞춘 뒤 하드웨어 없이 모형과 가상 USB를 확인합니다. [B25 파일](../mechanical/revisions/b25/README.md) · [하드웨어 없이 실행](../control/README.md#하드웨어-없이-실행)
2. 시험 출력물의 건식 맞춤과 모터를 뺀 첫 통전에서 끼움, A5 입력·출력 극성과 OpenRB 응답을 확인합니다. [건식 맞춤](../mechanical/revisions/b25/01-seoul-print.md) · [첫 통전](../control/README.md#모터를-뺀-첫-통전)
3. 조립품에서 실제 중립과 스토퍼 여유를 재고, 먼저 한 축씩 방향·간극을 확인합니다. P01–P08의 최종 결과는 해당 CAD와 보정값으로 조립한 기구에서 기록합니다. [보정과 한 축 구동](../control/README.md#보정과-한-축-구동) · [실물 시험](bench.md#b25-실물-시험)

## 근거를 맞추기

- 현재 검토할 CAD, 출력 프로젝트, 조립 순서, 배선과 펌웨어를 먼저 식별합니다. 이전 계산은 원래 리비전과 조건을 표시합니다. 재사용 근거는 동일한 형상·부품·자세·조건을 현재 B25에서 대조해 남깁니다.
- 가동 범위의 간극과 토크는 자중, 설정 가속과 지정한 마찰·공차를 적용합니다. 외장 5 N 시험은 파손, 영구 변형과 이탈을 봅니다. 공칭에서 이미 기준을 위반하는 한 자세나 경로는 해당 검사의 불합격 근거가 됩니다.
- 조립과 정비는 체결품과 대상 배선을 포함한 단계별 상태에서 검사합니다. 기본 체결품은 M3 원통머리 육각렌치 나사와 일반 육각너트입니다. 구매품에 지정된 예외 나사는 자리별로 기록합니다. 너트는 일반 스패너로 잡을 수 있게 하고, 뒤 배선 덮개와 아래 보드 덮개는 나사를 전부 풀어도 너트가 남아야 합니다. [10·13절](conditions.md) · [B25 체결품 배정](../mechanical/revisions/b25/assembly.md)
- 맞춤 게이지에는 모델 지름을 표시하고 사용한 출력 설정, 고른 전체 부품 파일, 실제 조립 치수와 유격을 기록합니다. 이전 리비전 시험판은 두 설계에서 치수가 같은 자리의 예비 확인에 쓸 수 있습니다. [B25 맞춤 게이지](../mechanical/revisions/b25/fit-gauge.md)

## 판정을 남기기

`python spec/verify.py --revision B25`의 `PASS`는 표시된 검사 범위에만 해당합니다. S01·S01b 모형 결과와 P01–P08 실측을 함께 보관합니다. C01–C04 및 S06은 검사기에서 계속 `UNVERIFIED`로 표시되므로 가동·조립·공구·공차·체결의 판정 근거를 별도로 검토합니다. M01–M09와 P01–P08의 누락되거나 리비전이 다른 기록도 `UNVERIFIED`입니다. [판정 범위](requirements.md#b25-인수-검사) · [기록 형식](records/README.md)

| 판정 | 적용 |
| --- | --- |
| 막음 | 현재 자료에서 고정 조건 위반이 재현됐습니다. 영향받는 전체 출력·구매 전에 처리할 항목입니다. |
| 시험판에서 확인 | 계산 또는 실물 근거가 아직 필요합니다. 남은 계산과 실물에서 잴 값을 구별해 적습니다. 7절의 유격은 계산값이 기준을 넘더라도 실측으로 판정합니다. |
| 나중 | 현재 범위 밖이거나 고정 조건에 포함되지 않은 항목입니다. |

기록에는 해당 조건 번호, CAD 또는 부품 파일, 실패 위치나 실측값을 남깁니다. 판정이 끝난 항목은 형상·조건이 바뀌거나 새 실물 결과가 나왔을 때 다시 엽니다. 추가 하중이나 다른 전압이 필요하면 0절의 조건 추가 제안 절차를 따릅니다. B25의 동결 이후 재검토는 시험판·게이지 결과나 별도 요청이 들어온 범위에서 합니다.
