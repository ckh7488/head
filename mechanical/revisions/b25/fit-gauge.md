# B25 맞춤 게이지

[맞춤 게이지 3MF](R5-B25-Fit-Gauge.3mf) · [이전 B15 P2S 시험판](../../R5-B15-Fit-P2S.3mf) · [B25 실물 검사](../../../spec/bench.md#b25-실물-시험)

Bambu Studio에서 게이지 3MF를 프로젝트로 엽니다. **P2S, PETG HF, 0.4 mm 노즐, 0.20 mm 층, Textured PEI** 설정으로 한 장을 출력합니다. B15 시험판은 B25와 같은 자리의 예비 확인에 씁니다. 게이지가 식으면 실제 사용할 베어링·핀·나사를 시편에 손으로 맞춰 보고, 선택한 모델 지름, 실제 부품 외경과 출력 홀 치수, 조립 후 유격을 기록합니다.

게이지와 맞는 파일 하나를 골라 B25 출력 프로젝트의 해당 부품을 교체합니다. STL은 기존 방향을 유지합니다. H4 일체형 턱은 별도 3MF로 열어 출력합니다. [턱 이탈 방지 판정](jaw-relief-attempts.md#b25-마지막-국부-수정) 해당 판의 서포트와 부품별 벽·채움 설정을 유지합니다. B10 오른쪽 받침 37은 얇은 벽 감지를 사용합니다. L2와 S4는 고정 2절 범위를 다루는 보정 파일을 선택합니다. 회전·미끄럼 홀은 실제 지름 차 0.3–0.5 mm와 조립 유격을 모두 확인합니다. 고정 핀은 원래의 고정 방식과 조립 후 유격을 확인합니다.

- B100은 베어링 외륜을 원호에 대보는 시편입니다. 원 전체의 타원·휨은 선택한 부품에서 확인합니다. Ø100.40·100.50 mm는 스토퍼 홈 옆 벽이 각각 0.41·0.36 mm라 해당 크기의 전체 출력 파일을 제외했습니다. [목 베어링 벽과 치수](fit-large-bearings.json)
- 24 눈꺼풀 레일은 수평 Ø10.24 자리와 Ø9.36 멈춤턱을 유지합니다. 내부 지름을 확인한 뒤 두 베어링을 기존 금속 시임으로 맞춥니다. B10은 37번 턱 시트에 사용합니다. [레일 마감과 시임](bearing-fit.json)
- 조립서에 드릴·리머 마감이 지정된 홀은 해당 가공서 치수를 사용합니다. 베어링 내륜과 금속 핀처럼 금속끼리의 끼움은 해당 구매품을 직접 대봅니다. M3 시편은 공통 관통홀의 출력 편차를 확인합니다. 원본 M3 통과홀을 쓰되, 전체 부품의 크기별 M3 파일은 포함하지 않았습니다. [기존 가공](../b24/assembly.md) · [전체 제작을 막는 체결](review-disposition.md)

## M3 열압입 인서트

오른쪽 아래 두 줄이 **CNC Kitchen TC-M3×3.0** 시험편입니다. L2 오른쪽은 수직 홀, M2 오른쪽은 수평 홀입니다. 왼쪽부터 모델 지름 **3.95, 4.05, 4.15, 4.25, 4.35 mm**이고 막힌 홀 깊이는 **4.50 mm**입니다. 모델 Ø4.15 mm는 고정 조건의 출력 수축 0.15 mm를 적용할 때 제조사가 제시한 Ø4.0 mm의 시작점입니다. 실제 홀을 재고, 인두로 면과 수평하게 장착한 뒤 식혀서 나사가 잘 들어가는지 확인합니다. [제조사 치수와 가이드](https://cnckitchen.com/s/CNCKitchen_Heat-Set-Insert-Dimensions-and-Design-Guidelines.pdf)

[Ø8 축 맞춤 치수](shaft-fit.json) · [핀 부품의 크기 양끝 슬라이스](pin-fit-options-check.json) · [M2·소형 베어링 크기 양끝 슬라이스](mount-fit-slice.json)

갱신된 P8·B10·M2(ID6)·H4 치수 파일은 각 다섯 개를 형상 검사했고, 규격마다 가장 큰 지름을 슬라이스했습니다. [치수별 출력 파일 검사](fit-variant-slice.json)
