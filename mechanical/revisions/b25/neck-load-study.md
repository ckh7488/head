# 목 상하축 직접 1 N 접촉 후속 설계

B25의 목 상하축은 직접 1 N 접촉 조건을 통과하지 않았습니다. 기준 B24 형상에서 20.61°/s 전시 구동 중 따뜻해진 XL430의 계산 출력은 **0.105 N·m**였습니다. 접선 방향 1 N을 외장에 가하면 **0.176 N·m**, 가장 먼 턱 지점까지 포함하면 **0.204 N·m**가 필요했습니다. 중력을 이상적으로 상쇄해도 후자는 **0.180 N·m**입니다. 기존 스토퍼는 전원 차단과 1 N이 겹치면 허용 추가 회전량 **뒤 0.76°, 앞 1.16°**를 넘습니다. [B24 구동 하중](../b24/force-path.json) · [B24 스토퍼 해석](../b24/pitch-strength.json)

## 기준 입력 재현

기준은 저장소의 B24 FCStd와 P2S 슬라이스 질량표입니다. 기준 FCStd SHA-256은 `8c1b2700daa8e3b3d4c99ddfbf6d0c149cbc0952d44f5add68c199aa5101a3e2`입니다. 상하축 설정은 `b096213`에서 XL430, PWM 185, 전시 속도 15틱, 일반 속도 19틱, 가속도 10틱입니다. FreeCAD Python과 기구 검사 의존성이 설치된 환경에서 저장소 루트에서 실행합니다. [실행 환경](../../README.md#재현) · [기구 검사 의존성](../../physics/requirements.txt)

```sh
b24=mechanical/revisions/b24
out=build/neck-load-study
native="$b24/R5-B24-Assembly.FCStd"
python mechanical/physics/export_cad.py --world --cad "$native" "$out/cad"
python mechanical/physics/b23_force_path.py "$native" "$out/cad" "$b24/sliced-grams.json" "$out/force-path.json"
python mechanical/physics/b22_pitch_stop_load.py "$out/cad" "$b24/sliced-grams.json" "$out/pitch-loads.json" \
  --command-angles -14.326171875 3.69140625 --stop-angles -16.46 5.97 --initial-body-offset-deg 1.36
python mechanical/physics/b22_pitch_stop_strength.py "$native" "$out/pitch-loads.json" "$out/pitch-strength.json" --mesh-mm 1.6 1.4
python mechanical/physics/b23_motion_replay.py "$out/cad" "$b24/sliced-grams.json" "$b24/jaw-stop.json" "$out/replay"
```

위 명령은 기준 모델을 다시 실행합니다. 직접 접촉 토크 비교는 `b23_force_path.py`의 `joint_wrenches`와 `b20_dynamics.py`의 `capacity`에 상하축 접촉 토크 **±0.098665 N·m** 또는 **±0.126355 N·m**를 넣습니다. 엔코더 가드 범위 101점, 턱 0–8°를 1° 간격으로, 각 축은 정지 및 허용 속도·가속도의 두 부호를 사용합니다. 상하 속도는 끝점까지 제동 가능한 값으로 제한합니다. 상하축 단자 10.62 V, 정지 토크 계수 0.55, 미끄럼 마찰 0.042 N·m, 점성 계수 0.009 N·m·s/rad을 적용했습니다. 20.61°/s는 전시, 26.106°/s는 일반 구동 상한입니다. [구동 식](../../physics/b23_force_path.py) · [모터 모델](../../physics/b20_dynamics.py)

## PETG와 국부 금속 보강 후보

| B24 객체 | 6061-T6 후보 영역과 기준 체적 |
| --- | --- |
| `Part011` 07 요크 | 월드 X **−54…−51 mm**, **−42…−39 mm** 슬라이스. 각각 **4,254.33**, **1,594.59 mm³** |
| `Part019` 09 머리 프레임 | 월드 X **−59…−34 mm** 슬라이스, **15,087.73 mm³** |
| `Part016` 08 혼 클램프 | 외곽 전체 **2,373.65 mm³**. 강철 Ø8 축에 맞춰 D면 밀착과 M3×8 결합을 가공·검증 |

FreeCAD 월드 솔리드를 해당 X 구간과 교차시켜 위 영역을 정의합니다. 나머지는 PETG입니다. 밀도 2.70 g/cm³와 기존 슬라이스 질량을 사용하면 좌우 회전부에 **9.94 g**, 상하 회전부에 **29.14 g**이 늘어납니다. 07 분할에서 작은 외측 귀 조각이 별도 솔리드로 남으므로 보강재와 함께 고정되도록 다시 설계해야 합니다. 08은 기존 출력물의 D면 틈을 그대로 두면 강성이 커진 뒤 체결로 닫기 어렵습니다. [기준 축과 클램프 가공](../b24/pitch-coupler.md)

유한요소 비교는 `b22_pitch_stop_strength.py`의 1.6 mm 메시, 선형 사면체와 동일한 양쪽 핀 압력·베어링 반력을 사용했습니다. 위 슬라이스에 요소 중심이 들어가면 금속을 적용했고, 소재 경계는 완전 결합으로 두었습니다. 낮은 강성 조건은 PETG/6061 **0.50/50 GPa**, 높은 조건은 **1.80/69 GPa**이며 모델 포아송비는 모두 0.37입니다. 스토퍼 닿는 팔 길이는 뒤/앞 **35.310/32.947 mm**입니다. 들기·숙이기 방향으로 150 ms 동안 1 N 접선 하중을 가하는 조건에서 전 스트로크의 힘 일을 상한으로 두고, 전원 차단 직전 45°/s도 반영했습니다.

| 값 | 뒤 | 앞 |
| --- | ---: | ---: |
| 차단·접촉 에너지 상한 (J) | 0.05044 | 0.05409 |
| 중력·접촉으로 닫히는 토크 (N·m) | 0.13473 | 0.15073 |
| 낮은 강성 요크 / 프레임 변위율 (mm/N) | 0.000528 / 0.000550 | 0.000347 / 0.000565 |
| 높은 강성 요크 / 프레임 변위율 (mm/N) | 0.000238 / 0.000331 | 0.000148 / 0.000334 |

위 두 변위율에 기존 강판·핀의 **0.000032 mm/N**과 새 요소의 변위율을 더한 값을 `C`로 둡니다. 팔 길이 `L`을 mm로 넣으면 각강성 `k = L²/(1000 C)`입니다. 위 표의 에너지 `E`와 토크 `T`에서 추가 회전은 `θ = (T + √(T² + 2kE))/k`, 접촉력은 `F = 1000 kθ/L`입니다. 베어링 반력의 비교값은 `1.15F + 8 N`입니다. 높은 강성에서 직렬 변형을 추가하지 않으면 최대 **541 N**, 프레임 국부 **182 MPa**로 계산됩니다.

새 요소의 목표는 유격 없이 충격 하중에서 **0.00025–0.00040 mm/N**의 할선 변위율입니다. 두 소재 강성 조건에서 계산한 추가 회전은 **0.481–0.674°**, 접촉력 **262–381 N**, 베어링 반력 비교값 **310–446 N**, 프레임 국부 응력 **110–150 MPa**입니다. Ø4×20 핀과 3×12 mm 강판의 위치를 먼저 유지합니다. 핀 귀의 Ø4.10 mm 구멍을 Ø5.10 mm로 넓히는 솔리드 연산은 성립했습니다. Ø4 핀을 받는 탈착식 탄성 슬리브는 이 공간을 쓰는 시제품 방향이며, 조립 후 예압과 양방향 변위율 및 슬리브·핀 이탈 방지를 측정해야 합니다. 스토퍼 첫 접촉 각도와 기존 피치–턱 간섭 한계는 [B24 스토퍼 검사](../b24/neck-stop.json)를 참조합니다.

## 다음 제작 전 확인

- 국부 보강 질량으로 1 N 구동 하중은 전시 **0.1973 N·m**, 일반 **0.1976 N·m**였습니다. XL430으로 따뜻한 조건에서 0.020 N·m 계산 여유를 두려면 PWM **323/338**이 필요합니다. PWM 338의 12 V 정지 상한 계산값은 **0.573 N·m**입니다. 새 08 클램프와 축은 양방향 **±0.65 N·m**를 작업대에서 입증해야 합니다. 50 mm 시험 팔에서는 각 방향 **13 N**입니다. B24의 기존 ±0.12 N·m 작업대 기준으로는 이 변경을 승인할 수 없습니다. [기존 체결부 시험](../b24/pitch-coupler.md#작업대-확인과-최종-조립)
- 기존 688의 정적 한계 710 N에 안전계수 1.5를 적용해 **473 N**과 비교했습니다. 왼쪽 Ø8 축은 X −66 mm 끝에 횡하중 **446 N**을 가하고 베어링 자리 X −54…−49 mm를 지지한 0.7/0.5 mm 메시에서 국부 응력 **165/187 MPa**였습니다. 실제 재료와 조립된 지지로 이 하중의 시험이 필요합니다. 더 큰 베어링은 하우징 수정이 필요합니다. 698은 하중 여유가 있지만 외륜 구속을 다시 설계해야 하고, 608은 기존 요크를 그대로 넓히면 지지면이 크게 줄었습니다. [NSK 정적 정격](https://www.nsk.com/engineering/688amc5-apn.html)
- 보강재 고정, 공구 접근, 슬리브 물성·온도 민감도, 스토퍼와 턱의 동시 간섭을 실제 후보 형상으로 다시 검사합니다. PWM 338과 후보 질량을 넣은 무접촉 재생에서 S01 획득은 **0.732–0.744초**, 시선 성공률 **96.24–96.27%**, 목 최고 속도 **44.11°/s**, 정면 복귀 최고 **10.96°/s**였습니다. S01b 최대 초과 회전은 **0.72° 미만**이었습니다. S02의 기준 눈축 위치와 명령각은 그대로 둡니다. 이 재생과 완전 결합 계산으로는 실제 체결부, 접촉 시 동작, B25 조립이 검증되지 않습니다. [장면 기준](../../../spec/requirements.md#동작-장면) · [실물 검수](../../../spec/bench.md)
