# 3. 시험 맞춤 뒤 발주할 전장과 배선

서울 시험에서 끼움 지름을 고르고 P08의 건식 조립과 오른쪽 요크 실제 간극을 확인한 뒤 아래 부품을 발주합니다. 수량은 **R5 한 대** 기준입니다. 모터·카메라·전원이 필요한 구동과 USB 1,000회 검사는 입고 후 조립품으로 진행합니다. [서울 출력 목록](01-seoul-print.md) · [실물 검사](../../../spec/bench.md#b25-실물-시험)

모델 지정품은 조립 치수와 제어 설정에 맞춰 고릅니다. 전원, 전선, 체결품과 수동소자는 아래 규격의 국내 유통 동급품을 쓸 수 있습니다. 커넥터는 키 방향, 핀 배치, 고정턱과 기판 풋프린트가 같은 호환품을 고릅니다.
