# B25 오른쪽 목 상하축 가공

오른쪽 금속 축은 모터 쪽 끝에서 7.20 mm 떨어진 위치에 D면과 수직으로 **Ø2.50 mm 관통 구멍**을 뚫은 뒤 **M3×0.5 관통 탭**을 냅니다. 가공 도면과 STEP의 탭 전 파일럿은 모두 Ø2.50 mm입니다. 가공 치수와 탭 지정은 도면을 따릅니다. [가공 도면](pitch-drive-shaft-B25.svg) · [가공용 STEP](pitch-drive-shaft-B25.step)

| 금속 축 | 치수 |
| --- | --- |
| 소재와 원형 기준 | S45C 등 가공 가능한 강철, Ø8 h7 × 27.30 mm |
| 모터 쪽 D면 | 모터 쪽 끝에서 길이 9.95 mm, 깊이 1.00 mm |
| 구동 나사 구멍 | 모터 쪽 끝에서 중심까지 7.20 mm, D면에 수직, Ø2.50 mm 관통 드릴 후 M3×0.5 관통 탭 |
| 프레임 평행핀 구멍 | 바깥쪽 끝에서 중심까지 5.50 mm, D면에 수직, Ø3.00 mm 관통 |

P2S 6번 판의 08번 출력 클램프는 M3×8 나사가 통과하도록 **Ø3.10 mm**로 손질합니다. 조립본의 금속 축 `Part015`에는 나사 외형의 간섭 검사에 쓰는 Ø3.10 mm 공간이 들어 있습니다. 금속 축 가공에는 이 페이지의 도면과 STEP을 사용합니다. [조립과 작업대 확인](../b24/pitch-coupler.md#작업대-확인과-최종-조립)

원본 검토 대상의 STEP에서 Ø3.10 mm가 측정됐습니다. B25 STEP을 FreeCAD에서 다시 읽어 Ø2.50 mm 파일럿과 기존 Ø3.00 mm 프레임 핀 구멍을 확인했습니다. [원본 검토](https://github.com/ckh7488/head/blob/765d379f9c37a0123b0e38612cc2745b216bceca/REVIEW.md#기구조립-검토-결과)

FreeCAD Python 환경에서 저장소 루트에서 실행하면 B25 조립본의 축과 클램프를 대조하고 가공용 STEP을 다시 내보냅니다.

```sh
python mechanical/build_b25_pitch_shaft.py build/b25/pitch-drive-shaft-B25.step
```
