# B27 · 1단계 검토 결과

31번 눈 테두리와 32번 눈꺼풀의 안쪽을 재설계했습니다. 최신 통합 시안은 고정 간극 및 출력 형상 검사를 통과했습니다. 목표 외피 안쪽 **3.0 mm** 여유와 기본 구동 검사 판정이 남아 1단계 상태는 보류입니다.

## 반영한 형상

- 31번의 바깥쪽 힌지 귀를 안으로 옮기고 32번의 짧아진 힌지에 Ø8.65 mm 보강 칼라를 만들었습니다. 좌우 바깥 핀은 지름 2 mm, 길이 5.95 mm입니다. 눈꺼풀의 바깥 곡면은 기존 형상을 사용합니다.
- 13번의 MR63 베어링 자리를 좌우 각각 8.29 mm 안쪽으로 옮겼습니다. 오른쪽 받침은 링크 아래를 지나 09번에 닿습니다. 베어링 자리의 하단 안쪽 모서리에 85° 슬롯을 두고, 두 받침의 프레임 체결은 M3 × 6으로 잡았습니다.
- 12번의 양쪽 축 지지부와 오른쪽 구동 연결부를 새 위치에 맞췄습니다. 18번은 링크 내부의 꺾임으로 하단을 2.85 mm 옮겼습니다. 하단 핀은 2.70 mm 이동했습니다. 모터와 상단 접점은 B26 위치에 있습니다.
- 28·29번 해골과 30번 턱 외장, 안구·홍채·동공의 월드 메시 해시를 B26과 대조했습니다. 눈 상하축 YZ와 눈 상하 ±8°, 눈 좌우 ±20°, 눈꺼풀 −1…91°의 검사 범위가 일치합니다.

간극·출력 판정은 인수 시점의 조건과 검사기 Git 원본을 사용했습니다. 31·32 적용본은 중립 자세의 정면 투영에서 0.35 mm 간격으로 비교한 결과, 눈 주변에서 깊이 또는 처음 보이는 면이 달라진 표본이 초기 시안 736개에서 개정안 11개로 줄었습니다. 옆 시점에서는 힌지 귀의 안쪽 형상 변화가 보입니다.

## 남은 항목

1. **오른쪽 13번 위쪽에 외피 여유가 부족합니다.** 최종 시안은 목표 겉면에서 3.0 mm 안쪽이어야 하는 경계를 측면 광선 표본에서 최대 **1.24 mm** 넘었습니다. 위쪽을 깎은 시안은 최대 초과가 0.98 mm로 줄었지만, 0.8 mm 미만 면적이 **4.6 mm²**로 늘어 허용 2.0 mm²를 넘었습니다. 최종 시안의 해당 면적은 **1.0 mm²**입니다.
2. **09번 하단과 오른쪽 23번의 가림을 확인해야 합니다.** 기존 09번 하단의 턱 체결부에 3.0 mm 여유 밖 표본이 남습니다. 왼쪽과 오른쪽 09번의 측면 투영 초과량 98백분위는 각각 **8.99 mm, 7.39 mm**입니다. 이 위치를 안으로 옮기려면 턱 받침과 기존 체결 자리도 함께 볼 필요가 있습니다. 23번 링크는 B26 위치이며, 오른쪽 하단에서 초과 표본 **3개**가 나왔습니다. 인수 지시의 최종 노출 판정에는 관자와 하악지 외피를 포함한 18개 검사 시점이 필요합니다.
3. **기본 구동 검사에 기존 모터 메시 접촉 1쌍이 남습니다.** `Part041`과 `Part064`의 FreeCAD 교차 체적은 0 mm³입니다. 동일 위치에서 모터의 개별 솔리드 표면을 닫아 합친 진단 메시의 구동 결과는 0쌍입니다. 기본 내보내기 결과는 위 표의 1쌍을 유지합니다.
4. **재배치한 받침의 조립과 고정은 확인이 필요합니다.** 새 M3 체결 방향의 렌치 접근, 축 방향 베어링 고정과 정렬, 31·32번 바깥 핀의 압입·회전을 확인해야 합니다. 간극과 벽 두께 판정은 좌표에 설치된 형상의 결과입니다. 조립 경로, 3MF 슬라이스, 관자·하악지 덮개는 인수 지시의 후속 단계입니다.

초기의 짧은 받침 시안에서는 09번의 새 고정부가 목 요크와 **272.27 mm³** 겹쳤습니다. 오른쪽 받침을 위로 보내는 시안에서는 28번과 최대 **119.79 mm³** 겹쳤습니다. 모터를 2.7 mm 옮긴 시안에서 기존 모터와 24번 눈꺼풀 레일은 원본 솔리드 하나 기준으로 **310.77 mm³** 겹쳤습니다. 최종 시안의 낮은 받침 경로와 18번 링크 수정으로 해당 충돌을 제거했습니다.

## 재현

[생성 코드](../../build_b27_temple_inward.py)는 B26 CAD에서 실제 FreeCAD 시안을 만듭니다. `--lids-only`를 붙이면 31·32번과 바깥 힌지 핀을 적용한 시안을 생성합니다. 다음 검사 명령은 [인수 지시서](WORK.md)의 0·1단계와 같습니다. 단계 1에서는 빈 덮개 선언으로 `clearance`와 `print`를 실행합니다.

```sh
mkdir -p build/b27
python mechanical/build_b27_temple_inward.py \
  mechanical/revisions/b26/R5-B26-Assembly.FCStd \
  build/b27/R5-B27-Stage1.FCStd build/b27/changes.json
python mechanical/physics/export_cad.py --world --cad build/b27/R5-B27-Stage1.FCStd build/b27/cad
python mechanical/physics/check_b27_skull_cover.py \
  build/b27/cad build/b26/cad build/empty-covers.json build/b27/stage1-check.json --only clearance print
python mechanical/physics/check_head.py build/b27/cad build/b27/check-head.json
```

[최신 시안 검사 수치](diagnostics/stage1-native-results.json), [측면 3.0 mm 표본 스크립트](diagnostics/measure_temple_inset.py), [이전 배치 시험](diagnostics/stage1-results.json)을 같이 보관합니다. 측면 표본은 고정 자세 격자에서 기준 해골과 관자 채움에 X 방향으로 광선을 쏜 값입니다. 인수 지시의 덮개 노출 검사는 별도로 실행합니다.
