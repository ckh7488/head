## 제작할 파일 (B19 기준)

| 구분 | 사용할 파일 |
|---|---|
| 출력 | [B16 P2S 전체판 13장](b16/R5-B16-P2S.3mf) 또는 [P1S](b16/R5-B16-P1S.3mf). 7번 판의 07 요크는 [B18 요크와 ID5 가드 STL](b18/study/R5-B18-yoke-and-ID5-keeper.zip)로, 11번 판의 40·42번은 [B18 40번](b18/40-rear-cable-guide-B18.stl)·[42번](b18/42-rear-cable-cover-B18.stl)으로 바꿔 Bambu Studio에서 다시 슬라이스 |
| 시험 출력 | [B16 P2S 시험판](b16/R5-B16-Fit-P2S.3mf) |
| 구매품 | [부품표](../BOM.csv). 목 상하축 직교 구멍, 평행핀, 눈꺼풀 축 평면 0.30 mm는 B19 기준 |
| 조립 | [B15 조립 절차](../ASSEMBLY.md)에 B16 배선, B17 ID5 가드, B18 후면 연결, B19 축 고정을 더함 |

B18 개선 시안(고정 허브, 목 가림막)은 제작 전 검토 단계라 위 목록에 넣지 않았습니다.

[B15 조립 절차와 출력 설정](../README.md#b15-조립)은 B15 조립본에 해당합니다. B16 이후의 모델을 볼 때는 해당 개정의 출력판과 부품 설명을 함께 확인합니다. B18 개선 시안에는 추가 체결과 실물 확인이 필요한 부품이 있습니다.

후면 연결부와 개선 시안의 HTML에는 모델과 뷰어가 포함됩니다. GitHub에서 **Download raw file**로 내려받은 뒤 브라우저에서 엽니다.
