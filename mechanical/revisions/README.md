# R5 CAD 개정 이력

## 최신 제작 파일

현재 제작 기준은 **B25 기구, A5 서보 허브, PETG HF 18판·57개**입니다. [제작 순서와 파일](b25/) · [B25 조립 절차](b25/assembly.md) · [A5 전장](../../electronics/README.md)

## 이전 개정

| 개정 | 확인할 내용 |
| --- | --- |
| [B16](b16/) | 고정 길이 배선과 턱 DATA 굽힘, P1S·P2S 전체판과 시험판 |
| [B17](b17/) | ID5 플러그 가드와 300 mm 시선 정렬 |
| [B18](b18/) | 받침 밖 USB와 전원 플러그, 분리형 후면 트레이 |
| [B18 개선 시안](b18/study/) | 고정 허브, 30 mm 내려가는 바닥 덮개, 목 가림막과 12 V 배선 |
| [B19](b19/) | 모든 체결품의 길이, 조립이 안 되던 지점 수정, 출력물 10개 교체, 단계별 조립 검사 |
| [B20](b20/) | 타이바 직선 삽입, 출력 공차 검사, P2S 전체판, 배선과 체결품이 보이는 조립 뷰어 |
| [B21](b21/) | M3 체결과 공구 접근, 눈·눈꺼풀 평행핀, 턱 개방 스토퍼 |
| [B22](b22/) | 목 상하 양방향 제한판과 카메라 배선 |
| [B23](b23/) | 앞 외장 삽입, 눈 상하 링크, 목 좌우 스토퍼와 두 정비 덮개 |
| [B24](b24/) | 눈 상하 베어링, 목 축, 깜빡임과 추적 복귀 |

B21 자료는 [FreeCAD·P2S](b21/)와 [당시 조립 절차](../ASSEMBLY.md)에 있습니다.
