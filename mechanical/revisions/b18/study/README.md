# B18 고정 허브와 목 가림막 시안

HTML을 **Download raw file**로 내려받아 브라우저에서 엽니다. **목 가림막**에서 시점과 목 각도를 바꾸고, **받침과 덮개**에서 0~30 mm를 움직여 B18 기본 조립본과 시안을 비교할 수 있습니다. [B18 기본 조립본](../)

## CAD에서 확인한 내용

| 변경 | 확인 결과 |
| --- | --- |
| 허브 고정 | 두 레일로 허브를 기존 좌표에 지지합니다. 덮개 0~30 mm와 좌우·앞뒤 ±0.20 mm, 비틀림 ±0.22°를 포함한 87개 자세에서 겹침이 없었습니다. 닫힌 위치의 최소 간격은 0.24 mm입니다. |
| 목 12 V 경로 | 뒤에서 12 AWG를 18 AWG로 바꿔 고정 J2에 연결합니다. 두 선 모두 최소 굽힘 반경 9.39 mm로 6715 기준 8.763 mm를 넘었습니다. 새 전환부 공간과 10.1 mm 뒤로 옮긴 XT60을 배치한 상태에서 네 커넥터의 16 mm 탈착 경로와 손 공간을 확인했습니다. |
| 목 가림막 | 266개 검사 자세에서 가림막과 지지대 형상이 기구와 배선에 닿지 않았습니다. 목 좌우 0°·상하 −15°에서 카메라선의 보이는 중심 길이는 정면 58→12 mm, 왼쪽 143→117 mm였습니다. 뒤쪽과 왼쪽에는 노출이 남습니다. |

기존 20가닥의 모델 재단 길이에서 새 레일·덮개와 접촉이 없었습니다. XT60은 하우징을 케이블 축으로 180° 돌린 배치입니다. 전원 +는 J2+, 리턴은 J2−에 연결합니다. [6715 제조사 사양](https://www.alphawire.com/products/wire/ecogen/ecowire/6715)

## 제작 전 확인

가림막 지지대의 체결과 탈착, 뒤쪽 12 V 접속부의 보호와 당김 방지, 덮개와 레일의 출력 공차를 확인합니다. 5 V 루프 처짐은 실물 확인 항목입니다. 전환부와 지지대에는 공간 검사용 형상을 넣었습니다.

B16 전체 출력판의 7번 판에는 구형 요크가 들어 있습니다. B18의 ID5 가드를 달 때는 위 ZIP의 최신 07 요크와 ID5 가드를 함께 사용합니다.
