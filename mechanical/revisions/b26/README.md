# R5 B26 제작 자료

B26은 B25에서 **받침 01의 체결부와 벽 두께**를 고치고, 조립 점검에서 나온 **A5 J2 잠금쇠의 나사 머리 간섭**을 고친 리비전입니다. 받침의 열압입 인서트와 숨은 너트를 없애고, **관통 구멍 + 일반 너트**로 바꿨습니다. 볼트와 너트가 눈에 보이고 공구가 닿으며, 프린터 오차에 민감한 끼워맞춤이 없습니다. 외부 감사 두 번(2026-11-27)의 지적을 반영했습니다([아래](#외부-감사-반영)). 나머지 부품, 배선과 조립 순서는 B25와 같습니다. [B25 제작 자료](../b25/)

## 바뀐 곳

| 위치 | B25 | B26 |
| --- | --- | --- |
| 바닥 덮개 너트 4개 | 원기둥 자리에 넣고 누름판 2개를 M3×6과 인서트 2개로 덮음 | 양옆 막대에 **Ø3.7 관통 구멍**, 그 위에 **헐거운 육각 자리**(맞변 5.9 mm, 깊이 1.8 mm, 너트 5.5 mm). 너트를 손으로 떨어뜨려 넣으면 돌지 않고, 덮개를 떼고 받침을 옆으로 눕혀도 빠지지 않음. **덮개를 뗀 채 받침을 뒤집으면 너트가 2 mm 들려 빠지므로, 뒤집기 전에 너트를 빼 둠.** 너트 쪽 공구 불필요 |
| 목 좌우 브래킷 다리 4곳 | 위에서 M3×8 → 기둥 속 인서트 | 받침 밑 카운터보어에서 **M3×18**, 브래킷 다리 위에 **보이는 M3 너트**. 너트는 위에서 **5.5 mm 소켓(바깥지름 8.4 mm 이하)**으로 잡음. 카운터보어 천장은 원형 머리 받침면(약 15.2 mm²) 그대로이고, 출력 프로젝트에서 카운터보어 4곳에 서포트 차단 볼륨을 넣음 |
| 열압입 인서트 | 받침에 6개 | 받침에 0개 |

| 상판 03 볼트 통로 3곳 | 옆벽 1.0 mm | 옆벽 2.24 mm |
| A5 J2 잠금쇠 (출력물) | 허브 M3×12 머리(Ø5.56)가 옆 레일에 0.35 mm, 뒤 팔에 0.58 mm 겹침 | 레일과 팔을 바깥으로 넓히고 머리 자리를 **Ø6.3**으로 파냄. 머리 둘레 틈 0.37 mm, 받침과 0.55 mm, 내려 끼우는 길 겹침 0. 잠금쇠는 이 나사가 지나는 Ø3.3 구멍으로 자리가 잡혀(중심 여유 0.15 mm) 머리 틈은 0.22 mm 이상 남음 |

브래킷 다리 너트는 받침 컵 안쪽이라 일반 스패너(길이 100 mm)는 브래킷 벽·기둥·컵 벽에 막혀 돌릴 자리가 없습니다(자유 각도 0°). 위에서 바로 잡는 5.5 mm 소켓은 **바깥지름 8.5 mm까지** 닿고 8.6 mm부터 브래킷(Part008·009)에 막힙니다. 그래서 8.4 mm 이하 소켓이나 너트 드라이버를 씁니다. 사기 전에 끝 바깥지름을 확인하세요.

조립 단계는 171단계에서 168단계로 줄었습니다. 받침 인서트 단계, 너트 누름판 단계, 너트를 미리 넣는 단계가 빠졌습니다.

- **22단계**: 받침을 옆으로 세웁니다. M3 너트 네 개를 양옆 막대 위의 육각 자리에 손으로 넣습니다(헐거운 자리라 누르지 않음). 받침 밑에서 M3×10 네 개를 2.5 mm 육각렌치로 조입니다.
- **30단계**: 브래킷 다리 위에 M3 너트를 올립니다. 받침을 옆으로 세워 밑면 구멍으로 M3×18을 넣고, 위에서 5.5 mm 소켓(바깥지름 8.4 mm 이하)으로 너트를 잡은 채 밑에서 2.5 mm 육각렌치로 조입니다.

## 조립 절차 전체 점검

조립 화면의 168단계를 그대로 강체 점검기(`physics/check_b26_assembly.py`, B19–B25 점검기를 B26 절차와 체결품 위치로 실행)로 확인했습니다. 단계마다 부품이 정해진 방향으로 들어가는 길, 너트를 놓는 길, 나사를 넣는 길과 육각렌치가 닿는지, 잡아야 하는 너트에 스패너·소켓이 들어가는지를 봅니다.

| 결과 | 내용 |
| --- | --- |
| 막히는 단계 | **0** (168단계) |
| 고친 것 | A5 J2 잠금쇠와 허브 나사 머리 간섭(위 표), 정비 소켓 앞 평와셔 두 개를 넣는 방향(받침 안쪽에서), 덮개 너트 방향을 점검기 규약(±30°)에 맞춤 |
| 설계상 닿는 곳 11건 | 나사가 제 너트에 물리는 곳 2, 납땜 컵과 선 4, 결합된 플러그 외형 4, 코 트레이의 나일론 타이 1. 점검기에 이 쌍과 이유를 적어 두었고, 다른 접촉은 그대로 막힘으로 남깁니다 |

같은 점검을 B25에 돌리면 171단계 중 8단계가 막혔습니다. 그중 실제 간섭은 J2 잠금쇠 하나였고, 나머지는 위의 설계상 접촉과 점검기 설정 문제였습니다.

## 벽 두께 보강

받침 전체를 다시 재서, 2 mm보다 얇으면서 옆에 다른 것이 없는 곳은 모두 두껍게 했습니다. 공구 길이나 덮개를 좁히는 얇은 조각은 깎아 없앴습니다.

| 위치 | 전 | 후 |
| --- | --- | --- |
| 베어링 받침 기둥 3개 | 벽 1.94 mm, 나사 머리 밑 막 1.15 mm | 벽 2.54 mm, 막 2.0 mm. 나사 M3×16 → **M3×18** (너트 위로 1.6 mm, 회전판까지 13 mm) |
| 상판 볼트 통로 3곳 | 옆벽 1.0 mm | 2.24 mm |
| 옆 창 가운데 기둥 | 0.5 mm | 없앰 (스패너 자유 각도 35° → 55° 이상) |
| 옆 창 끝 칼날 | 0–1 mm | 끝 3 mm 잘라 2.8 mm |
| 덮개 구멍 모서리 뾰족한 끝 8곳 | 0.1–0.4 mm | 없앰 (덮개가 닿는 면은 그대로) |
| 뒤 가이드 소켓 길 옆 얇은 벽 | 1.1 mm | 2.6 mm 이상 (소켓 길은 그대로) |
| 오른쪽 창 지붕 끝 | 0.1 mm | 2 mm |

그대로 둔 곳: 바닥 덮개 플랜지 옆 바깥 치마 1.3–1.6 mm (두껍게 하려면 덮개 35를 바꿔야 함), 왼쪽 기둥의 트인 쪽 1.94 mm와 바깥 띠 1.4 mm (용도를 확인하지 못한 틈 옆), 1 mm² 남짓한 창 턱 1.88 mm·지붕 1.78 mm. 2 mm 미만 면은 30919점에서 4536점으로 줄었습니다(점 하나 0.185 mm²).

검사: 모든 부품과 겹침 0, 베어링 받침·캐리어·브래킷·상판을 내리는 길 겹침 0, ID4 옆 나사 2 mm 렌치 길 최소 틈 0.37 mm (B25와 같음). 감사 반영 뒤 다시 재도 2 mm 미만 면은 모두 위의 '그대로 둔 곳'뿐입니다.

## 왜 끼워맞춤을 없앴나

처음 B26은 너트를 맞변 5.6 mm 육각 자리에 눌러 끼웠습니다(너트 5.5 mm). 이 방식은 프린터 오차가 ±0.05 mm 안이어야 맞고, FDM은 구멍이 0.1–0.2 mm 작게 나오는 일이 흔해 받침을 다시 뽑을 위험이 컸습니다. 지금 덮개 너트 자리는 맞변 5.9 mm로 너트보다 0.4 mm 크고, 모든 구멍은 나사보다 0.4 mm 이상 큽니다. 출력 오차가 ±0.2 mm여도 너트는 손으로 떨어져 들어가고, 자리가 너트를 돌지 않게 잡습니다. 그래서 받침을 뽑기 전 시편도 필요 없습니다.

한때 덮개 너트를 막대 위에 그냥 올리고 스패너로 잡게 했으나, 외부 감사에서 덮개를 떼고 받침을 눕히면 너트가 막대에서 미끄러져 떨어진다는 지적을 받아 지금의 헐거운 자리로 바꿨습니다.

너트를 바닥 덮개 밑에 두는 안도 검토했습니다. 그러면 나사 머리가 받침 안쪽에 남아 돌지 않게 잡을 방법이 마땅치 않고, 덮개에 Ø8.6 소켓 구멍을 파야 하며, 덮개를 뗄 때 나사 4개가 받침 안에 남습니다. 그래서 너트를 막대 위에 둡니다.

## 다시 만들기

저장소 루트에서 FreeCAD Python 모듈과 기구 검사 의존성을 준비합니다. [웹 화면 만들기](../../../web/README.md#b25-웹-화면)

```sh
export PYTHONPATH="$PWD/mechanical:$PWD/mechanical/physics:/usr/lib/freecad-python3/lib"
out=build/b26
rev=mechanical/revisions/b26
python mechanical/build_b26_base_fasteners.py mechanical/revisions/b25/R5-B25-Assembly.FCStd "$rev/R5-B26-Assembly.FCStd" --edits "$out/edits"
python mechanical/build_b26_print.py mechanical/revisions/b25/R5-B25-P2S.3mf "$out/edits" "$rev/R5-B26-P2S.3mf"
python mechanical/physics/export_cad.py --world --cad "$rev/R5-B26-Assembly.FCStd" "$out/cad"
python web/b19/build_b19_viewer.py "$out/cad" mechanical/revisions/b24/hardware.json mechanical/revisions/b24/hardware-spec.json \
  --revision B25 --label B26 --revision-dir "$rev" --assembly-cad "$rev/R5-B26-Assembly.FCStd" --output "$out/assembly-assets" --preview
python mechanical/physics/check_b26_tool_access.py "$out/cad" "$out/assembly-assets/steps.json" "$rev/tool-access.json"
python mechanical/physics/check_b26_assembly.py "$out/cad" mechanical/revisions/b24/hardware.json mechanical/revisions/b24/hardware-spec.json "$rev" "$rev/assembly-check.json" --source "$rev/R5-B26-Assembly.FCStd"
npm ci --prefix web
node web/b19/compress_model.mjs "$out/assembly-assets"
python web/b19/pack_standalone.py "$out/assembly-assets" "$out/site/assembly" --revision B26 --preview --hosted
python web/export_b25_motion.py "$rev/R5-B26-Assembly.FCStd" "$out/cad" "$out/motion"      # 3D 구동 화면 (meshopt로 압축해 web/assets/b25-motion에)
python web/wiring-review/export_pose_data.py "$out/cad/cad_parts.json" "$out/pose-data.json"
R5_ASSEMBLY="$rev/R5-B26-Assembly.FCStd" node web/wiring-review/package_review.mjs "$out/cad" "$out/pose-data.json" "$out/site/wiring" "$(git rev-parse HEAD)"
```

`design.json`의 `cad_sha256`과 `p2s_sha256`은 새로 만든 FCStd와 3MF의 SHA-256으로 갱신합니다.

- 받침 출력 뒤 막대 밑 서포트가 바닥 덮개 구멍 쪽에서 깨끗이 떨어지는지, 브래킷 다리 카운터보어 4곳의 천장 고리(폭 1.45 mm)가 서포트 없이 처지지 않았는지. 처졌으면 M3×18을 조여 평평하게 눌림.
- 덮개 너트가 육각 자리에 손으로 떨어져 들어가는지(안 들어가면 자리 벽을 줄로 살짝).
- 갖고 있는 5.5 mm 소켓의 끝 바깥지름이 8.4 mm 이하인지.
